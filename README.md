Grade Calculator (Python)
Project Description
- This project is a simple Grade Calculator written in Python. It asks the user to input their quiz, exam, and project scores, then calculates the average and displays the final numeric grade along with the corresponding letter grade.

Features
- Accepts user input for quiz, exam, and project scores
- Calculates the average grade
- Displays the final grade rounded to two decimal places
- Assigns a letter grade (A–F) based on the computed average

Technologies Used
- Python 3
- Command Line / Terminal

How to Run the Program
- Make sure Python 3 is installed on your computer.
- Download or clone this repository.
- Open a terminal or command prompt in the project folder.
- Run the program using:
- python grade_calculator.py
- Enter the required scores when prompted.

Grading Scale
A: 90–100
B: 80–89
C: 70–79
D: 60–69
F: Below 60

Sample Output
Enter quiz score: 85
Enter exam score: 90
Enter project score: 88

Final Grade: 87.67
Letter Grade: B

Purpose of the Project

This project was created to practice basic Python concepts such as user input, arithmetic operations, conditional statements, and output formatting.
